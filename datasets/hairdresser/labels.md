# Hairdresser / Barber intent taxonomy

Dataset domain: `hairdresser`

Labels represent human-intent classification targets, not execution instructions.

1. `AGENDAMENTO`
2. `CANCELAMENTO`
3. `REAGENDAMENTO`
4. `DISPONIBILIDADE`
5. `SERVICO`
6. `PRECO`
7. `PROFISSIONAL`
8. `HORARIO`
9. `ENDERECO`
10. `PREFERENCIA`
11. `CUIDADOS`
12. `PAGAMENTO`

The training set contains 14,808 examples: 1,234 examples per label.
The evaluation set contains 156 examples: 13 examples per label.

The dataset is synthetic and intended for intent-classification/fine-tuning experiments. It is not a source of professional hair-care advice.
